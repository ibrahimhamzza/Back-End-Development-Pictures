# Back-End Development Pictures

## Project Description

This project is a Flask-based backend application for managing pictures.

## Environment Setup

This project was created from the provided coding project template.

### Python Version

Python 3.9.x

### Virtual Environment

backend-pics-venv

### Setup Script

The setup script was successfully executed using:

bin/setup.sh

## Running the Application

Activate the virtual environment:

source backend-pics-venv/bin/activate

Run the application:

python app.py

## Testing

Run the tests using:

pytest

## API Features

- Health check
- Get all pictures
- Get picture by ID
- Create a picture
- Update a picture
- Delete a picture

## Technologies

- Python
- Flask
- REST API
- pytest
- JSON
